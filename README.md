# r.in.s1slc

A [GRASS GIS](https://grass.osgeo.org/) addon that imports
**Sentinel-1 TOPS (IW/EW) Single Look Complex (SLC)** SAFE products in
their native radar geometry, with SNAP-compatible debursting,
radiometric calibration, thermal noise removal, geolocation layers,
ground control points and the full product metadata.

```sh
# Radar geometry needs an unprojected (XY) project.
grass -c XY $HOME/grassdata/s1slc_sharjah -e
grass $HOME/grassdata/s1slc_sharjah/PERMANENT --exec bash

# List sub-swaths and bursts with their footprints.
r.in.s1slc -l input=S1A_IW_SLC__1SDV_20230112T142507_20230112T142534_046752_059AD8_A55D.zip

# Debursted complex signal of the bursts over Sharjah, with lat/lon layers.
r.in.s1slc input=S1A_IW_SLC__1SDV_20230112T142507_20230112T142534_046752_059AD8_A55D.zip \
    output=s1_20230112 swath=IW2 polarization=VV bbox=55.35,25.25,55.50,25.40 \
    measure=complex geometry=latitude,longitude

# Calibrated, noise-free sigma0 in dB.
r.in.s1slc -n input=... output=s1 swath=IW2 bursts=4-6 measure=db calibration=sigma0
```

## Why

SLC products carry the phase needed for interferometry and the full
resolution needed for coherent change detection, but GRASS has no
native reader for them: *r.in.gdal* sees each sub-swath as a stack of
overlapping bursts, with no debursting, calibration or metadata. This
module reads the product directly, zip included, and hands back
debursted, optionally calibrated rasters together with everything a
downstream coregistration or InSAR step needs (orbit state vectors,
burst timing, Doppler centroid and FM rate polynomials, geolocation
grid).

## Features

| Feature | Option | Notes |
|---|---|---|
| Input | `input=` | `.zip` (read in place), `.SAFE` directory or `manifest.safe` |
| Subset | `swath=`, `polarization=`, `bursts=` or `bbox=` | `-l` lists bursts and footprints |
| Debursting | default, `-b` to keep bursts | SNAP *TOPSAR-Deburst* rule, no resampling |
| Measures | `measure=complex,amplitude,intensity,db,phase` | complex → `_i`, `_q` maps |
| Calibration | `calibration=sigma0\|beta0\|gamma0` | bilinear LUT in range and azimuth time |
| Thermal noise | `-n` | range × azimuth noise vectors (IPF ≥ 2.9), power measures only |
| Geolocation | `geometry=latitude,longitude,height,incidence_angle,elevation_angle` | from the annotation geolocation grid |
| GCPs | always, `target=` to reproject | imagery group `POINTS` for *i.rectify* |
| Metadata | always | *r.support*, *r.timestamp*, history, `cell_misc/<map>/description.json` |
| Interferometry | `-b` | whole bursts with overlaps, for *i.sar.coregistration* (ESD) |

Output maps are named `{output}_{swath}_{pol}_{measure}`
(e.g. `s1_iw2_vv_i`); with `-b` a burst tag is added
(`s1_iw2_vv_b04_i`). One imagery group per image,
`{output}_{swath}_{pol}`, holds the maps and their GCPs.

## How it works

1. The SAFE product is read through GDAL virtual file systems
   (`/vsizip/` for archives): manifest, annotation, calibration and noise
   XML files, then the CInt16 measurement GeoTIFF of each selected
   sub-swath and polarization.
2. Each output line is mapped to a source line of one burst from its
   zero-Doppler azimuth time. In burst overlaps the switch happens at the
   middle of the overlap, as in SNAP; samples outside the annotated valid
   range are null.
3. Noise and calibration LUTs are evaluated per line, the requested
   measures computed in chunks of 512 lines and streamed to raw files that
   *r.in.bin* imports, keeping memory bounded for 25 000-sample swaths.
4. Metadata, timestamps, imagery group and GCPs are written per map.

The algorithms mirror the ESA SNAP microwave toolbox
(`Sentinel1Level1Directory`, `TOPSARDeburstOp`, `Sentinel1Calibrator`,
`Sentinel1RemoveThermalNoiseOp`). Sub-swaths are not merged
(*TOPSAR-Merge*).

## Requirements

- GRASS GIS 8.4 or later
- Python 3 with NumPy and the GDAL (`osgeo`) bindings

## Installation

```sh
g.extension extension=r.in.s1slc url=https://github.com/YannChemin/r.in.s1slc
```

or from a source tree:

```sh
make MODULE_TOPDIR=$HOME/dev/grass
```

## Tests

The tests build a small synthetic IW SLC product (three bursts,
calibration and noise LUTs, geolocation grid) whose values make every
step exactly checkable: deburst seams, calibration, noise removal,
geolocation, GCPs, metadata, zip input and failure modes.

```sh
grass --tmp-project XY --exec python3 -m pytest tests
```
